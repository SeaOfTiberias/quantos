# Nifty 50 Eigen-Factor Residual Mean Reversion — Methodology, Pre-Committed 2026-10-13 Before Any Result Exists

## Why this exists

The BankNifty test bed (`docs/STATARB_BANKNIFTY_METHODOLOGY.md`) FAILED
(`docs/STATARB_BANKNIFTY_RESULTS.md`: M1 profit factor 0.92, Sharpe
−0.24, calibration t −0.40). Fourteen same-sector stocks were never the
strategy the spec (`docs/statarb_duckling_strategy_spec.md`) describes.
The spec calls for a broad, multi-sector universe, several PCA factors
and 30–50 simultaneous positions. This run is the closest fair test of
that strategy the cached data allows. A FAIL here retires the
residual-mean-reversion family on NSE stock futures in this project.

The user chose Nifty 50 over Nifty IT. Nifty IT alone (about 10 names)
repeats the BankNifty breadth problem, and adding sectors one at a time
after a failure inflates the chance of a lucky pass.

**Do not edit this file after the validation has run.**

## What carries over from BankNifty unchanged

Code (`core/statarb/`), data source (cached F&O bhavcopy near-month
futures, roll-adjusted), 60-day residual regression, OU fit and s-score,
speed filter (1/(−ln b) < 30 days), exclusions (corporate-action jump
band, HDFCBANK merger window), trading rules (entry |s| ≥ 1.25, exits
s ≥ −0.50 / s ≤ +0.75, stop |s| ≥ 3.0, max hold 20 days, next-close
fills, results blackout ±5 trading days and close before a results
day), notional ₹5L per stock leg, cost model (`core/pairs/costs.py`
+ 2 bps/side slippage + a round trip per roll), calibration method.

## What changes

### Universe

The current Nifty 50 constituent list (`ind_nifty50list.csv` from
nsearchives, same fetcher as the sector lists). The same survivorship
caveat applies: no historical membership. Pure renames are spliced:
ZOMATO → ETERNAL, TATAGLOBAL → TATACONSUM (2020-02; added after the
data load showed the gap, before any backtest ran). SHRIRAMFIN is NOT
spliced to SRTRANSFIN: that change was an amalgamation, not a rename.
A demerged entity (TMPV from TATAMOTORS) is NOT
spliced; it takes part only once it has its own 252-day history. Recent
futures listings (BSE, JIOFIN, MAXHEALTH, …) take part only once they
have 252 days of futures history.

### Primary model: PCA5

Leave-one-out PCA, the paper's construction, with 5 factors instead
of 15, sized to about 50 names. For stock i on day t:

1. Peers = every other member with a clean 252-day return window
   (no gaps, no corporate-action jump).
2. Correlation matrix of the peers' standardised returns over the last
   252 days → top 5 eigenvectors → eigenportfolio weights v_kj / σ_j,
   each sign-fixed so its weights sum positive.
3. Regress stock i's last 60 returns on the 5 eigenportfolio returns,
   with intercept → residual → OU fit → s, as before.

Leave-one-out costs little with 49 peers and keeps the construction
identical to BankNifty.

### Secondary model: MKT_SECTOR (info only)

Two factors closer to the "duckling" analogy: (1) the equal-weighted
return of all peers; (2) the equal-weighted return of the stock's
same-sector peers. Sectors come from the cached NSE sectoral lists,
first match in this order: bank, IT, pharma ∪ healthcare, auto, FMCG,
metal, oil-gas ∪ energy, finance (non-bank, from `niftyfinance`),
realty, consumer durables, media. A stock with fewer than 2 same-sector
peers present that day is excluded from this model (about 11 names:
ADANIPORTS, ASIANPAINT, BEL, BHARTIARTL, ETERNAL, GRASIM, INDIGO, LT,
TRENT, ULTRACEMCO, TITAN).

### Results dates

NSE results **board-meeting** dates only (`corporate-board-meetings`
endpoint: 4 a year per symbol back to 2019, verified on SBIN, HDFCBANK,
AUBANK). The filings-metadata API used alongside it for BankNifty is
dropped: it is empty after about 2025-02 and would double the request
count for 50 symbols. The meeting day counts as the reaction day.

### Hedge cost

The PCA5 hedge spans up to 49 stocks. Each trade is charged as ONE
futures-equivalent hedge leg of notional N × Σ_j |h_j|. This
understates the number of instruments but ignores netting across a
book of many positions, which the paper relies on. Gross P&L is
reported alongside net so the cost assumption can be judged.

## Pass bar (PCA5; all required)

1. **Edge:** pooled net trades pass `has_positive_edge` (profit factor >
   1.0 AND Sharpe > 0.5).
2. **Stability:** profit factor > 1.0 in both chronological halves of the
   trade list, in exits from 2024-01-01 on, and in exits from 2025-01-01
   on. 2024–26 is where every mean-reversion candidate in this repo
   (pairs v1/v2, BankNifty) broke down.
3. **Calibration:** 10-day forward residual return > 0 for s ≤ −1.25,
   < 0 for s ≥ +1.25, Welch t of the difference > 2 (non-overlapping
   samples every 10th day).

MKT_SECTOR, per-sector slices (banks, IT, …) and per-year rows are
reported for information. None of them can turn a FAIL into a PASS.

## Also reported

- Average and maximum number of simultaneously open positions (does
  Nifty 50 actually deliver the 30–50 breadth the spec wants?).
- Exit-reason breakdown, per-symbol and per-sector P&L, exclusion
